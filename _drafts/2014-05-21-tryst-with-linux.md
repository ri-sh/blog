When I first installed Linux(Mandrake) on my desktop and made it dual boot with windows, my idea was to learn Linux while use windows for my regular use. But, I soon fell in love with Linux and decided to remove windows from the HD. This was viewed as arrogance by a couple of my friends because they thought that a desktop machine will be useless if it doesn't have windows. Windows was considered as an integral part of a PC.  
  
Now, I can't imagine life on windows though at college i have to use windows as on my ubuntu i cant catch the wifi . Every form of computing device I own runs Linux and only Linux. I have grown so much dependent on Linux that working in windows makes me feel less productive. I don't know how windows succeeded without even the basic features of a window manager such as, [sloppy focus](http://people.cs.uchicago.edu/~ahiorean/ahwm/sloppy-focus.html), multiple desktops, versatile taskbar, roll-up windows, etc.
